00 — Prologue

序章

若你玩过月亮计划旗下的作品，会更快进入状况；没玩过也不影响。

00.1世界观

本次剧本发生在都市的郊区。首脑的手伸不到这里，秩序也一样。

为了生存，你们搜集物资、搭建营地；为了了解郊区的现状，你们结识当地的 NPC。最终目标只有一个——逃离郊区，返回都市。

00.2星引者（GM）

在郊区迷路的时候，不妨看看星空，它们会把你引入命运的河流。

作为 GM，你需要相对熟悉月计世界观，才能在这片贫瘠的土地上引导幸存者。 你的职责是：设定鉴定难度、扮演 NPC、裁定规则边界，以及决定这群人什么时候该倒霉。

00.3幸存者（PL）

经过一番打探与方向确认，你们得知自己身处都市外围的郊区——此处无首脑干预， 危机四伏。想要重返都市的你们，尽管背景各异，却志同道合， 遂决定在郊区寻觅一处临时藏身之所。

人类的赞歌是勇气的赞歌。
不要对未知感到恐惧——在没有制度的郊区活下去，才是唯一的目标。

01.5学习技能

  • 背景技能：选定背景会自动获得相关「技能书」。
  • 技能书：从战利品、NPC 授予或购买获得。技能书学来的技能无法精通。
  • 复制核心：郊区最稀有的存在。持有它就能去「复制核心工作台」复制已战胜过的目标，学会它的一个技能或获得它的一件物品。BOSS 与郊区怪物的技能基本只能走这条路。
  • E.G.O 装备：前 L 公司的奇点技术，心灵的具象化。装备后自动学会对应的 E.G.O 技能。

01.6完成建卡

填完之后你应该有：一个背景与所属势力、分配好的六项属性、两张恐慌卡、势力给的装备与技能书，以及用技能书学到的 6 个基础技能 + 1 个守备技能。

02 — Survival

鉴定与生存

郊区的大部分时间不在战斗里，而在搜刮、制作和不要发疯上。

02.1属性鉴定

  1. GM 指定一项属性和一个难度等级。
  2. 投掷等同于你该属性数值枚的十面骰（最少 2 枚；装备与扮演可以增减枚数）。
  3. 每有一枚骰子结果小于你的属性值，算 1 次成功。
  4. 成功次数 ≥ 难度等级即为成功。
参考难度

1 简单　2–3 中等　4–5 困难　6+ 极难

02.2恐慌鉴定

理智值 ≤10 时，每个回合结束会自动进行一次「智力」鉴定：投 1d10， 结果 ≤ 智力 记【坚定 +1】，否则记【恐惧 +1】。

累计结果理智
坚定 ×3坚定心智，本次不会陷入恐慌→ 70
恐惧 ×3陷入恐慌，触发恐慌卡效果→ 30

任一侧计满 3 点后，两侧计数在下一个回合开始时清空。 另外，理智值首次跌到 30 或以下时会触发【士气低落】，无需鉴定， 一场遭遇战只触发一次。

02.3威力鉴定

面对可破坏的物体（门窗、巨石等），可以在破坏前用「技能」进行鉴定。 中途可以无限尝试，直到物体被破坏或触发其他事件。

02.5郊区的中立交易生物

有些郊区生物愿意和人类做交易。下次见到它们，也许能帮上忙。

  • 圣诞精灵（12 区）：对人类极具敌意，但有那么几个例外。掉落的装备、或者太大带不走的东西，贴上礼物标记，它们会做成礼物送到你的营地——收费是人类尸块。
  • 旅行沙虫：实在撤不下来时的最下策，用人类尸体交易，让它把你平安送回营地。它似乎不喜欢鲜活的人类，反而偏好腐烂发臭的——下次搜刮时看到尸体，不妨顺手带上。
  • 拟态物：只会拙劣模仿人类和怪物的动作，攻击性强但伤害不高，适合练手。

03 — Combat

战斗

整体框架接近边狱巴士，但改了两处：技能槽换成了行动币， 硬币换成了随机性更大的骰子。

混乱阈值

默认 2 条，位于最大生命值的 60% / 30%； 体质 > 7 减为 1 条（50%），敏捷 > 7 增为 3 条（80% / 50% / 20%）。 生命值掉过某一条就会【陷入混乱】，该条随即熄灭直到长休； 一次掉血事件最多触发一条（由高到低检查）。 【震颤引爆】会把所有阈值百分比永久前移，可叠加，同样在长休时重置。

03.2行动币

这是本作和原作差别最大的地方。

行动币没有上限，可以由技能 / 装备 / 消耗品提升。 回合开始时不足 3 枚的补满至 3 枚，已经超过 3 枚的保留，不削减也不负债。

使用技能不消耗行动币，发起对抗也不消耗——这是一场有胜算才出手的游戏。 行动币是容量，不是消耗品：你的币数 = 本次对抗里允许失败几次， 拼点过程中一枚都不会扣。

惩罚只影响拼点胜负，不影响最终伤害，对抗一结束即清空。 【不可摧毁】骰同样占用失败次数，但不吃惩罚，也不会在对抗结束时被摧毁。

对抗结束时，胜方摧毁败方 1 枚行动币——每次对抗至多 1 枚，已经 0 枚则无事发生。

0 币不等于不能防守

仍然可以应战，只是拼点威力额外 −3，且输一次就直接定胜负。

例

A 有 5 币 → 对抗失败被摧毁 1 → 4 币 → 队友技能回 2 → 6 币 → 下次对抗从"允许失败 6 次"开始 → 又失败被摧毁 1 → 5 币 → 下个回合因为已经 ≥3 币，不再补满。

03.3技能

基础技能最多装备 6 个。物理类型：斩击 / 打击 / 突刺；技能等级 Lv.1–3。 战斗中按 6-bag 抽取：从 6 个技能中抽 2 个作为【激活】、1 个作为【预备】； 用掉一个后由预备补位，再从本轮尚未抽到的技能里补一个新的预备，6 个抽完重新洗牌。

守备技能装备 1 个，无法主动发起对抗，只能在被【发起对抗】时选用。

守备类型效果
闪避双方同时出手，只拼一次；不消耗行动点也不碎币。平局算闪避成功
格挡直接受到伤害，减少等同于自己格挡骰数的伤害
反击直接受到伤害，同时对目标造成自己骰数的伤害
可拼点格挡拼点成功 → 无视本次伤害；失败 → 受伤并减免自己格挡骰数
可拼点反击拼点成功 → 对目标造成自己骰数的伤害；失败 → 受伤并仍然反击

E.G.O 技能需要消耗罪孽资源与理智值，每个 E.G.O 等级只能装备 1 个， 使用后会修改自己的罪孽抗性。角色【陷入恐慌】时，所有 E.G.O 强制切换为侵蚀形态。

03.4一张卡的多套数值

同一张技能卡可以挂多套数值，切换的是"当前用哪一套"，而不是换一张卡。两套机制互斥：

机制适用切换方式
觉醒 / 侵蚀仅 E.G.O【陷入恐慌】时强制切到侵蚀
训练等级 Ⅲ→Ⅳ→Ⅴ仅基础 / 守备每 3 级获得一次强化名额，升级时自选

训练等级：默认 Ⅲ 级，精通 Ⅳ 级，强化 Ⅴ 级。 切换训练等级不会改变名称 / 类型 / 分类 / 罪孽 / 等级 / 标签； 其余（骰式、骰子类型、反击分类、攻击容量与扩散、各种标记、理智消耗、星芒、 武器限制、描述、激活效果）每一阶各有一套。

强化名额落在 Lv3 / 6 / 9 / … / 48，满级 50 共 16 次。 可选的不限于已装备的 7 个技能——技能列表里没装上去的同样能挑。

部位修改限制

  • 带效果的装备可以【激活】触发，消耗 1 行动币。
  • 消耗品：战斗中每回合只能使用 1 次，不消耗行动币。
  • 背包：背包里的物品在战斗中既不能激活也不能使用，只能战前准备时与身上的替换。
  • 传说装备：占用大量星芒并配套专属技能，只能装备 1 件——工坊背景可以装 3 件。

03.6行动时点

回合开始时

  1. 所有角色重投「速度」决定先后顺序。
  2. 行动币不足 3 枚的补满至 3 枚（超过的保留）；恐慌 / 坚定计数若已计满 3 点则清空。
  3. 触发所有【回合开始时】的技能与装备效果。
  4. 从本轮第一位开始行动。

角色行动

  • 可以移动「速度 ÷ 5」格。
  • 可以【激活】装备 / 消耗品 / 守备技能，每次消耗 1 行动币（消耗品不消耗）。
  • 对范围内的 1 个目标使用【基础技能】或【E.G.O 技能】——这视为发起对抗。

对抗（拼点）

  1. 第一次投掷免费：攻守双方各投一次。
  2. 输一次 → 双方重掷再拼一次，并占用输方 1 次失败次数（上限 = 输方的行动币数）。
  3. 平局 → 不分胜负、不占用失败次数、不加惩罚，双方重掷再拼。
  4. 失败次数用满 → 彻底失败（3 币 = 允许失败 3 次，第 4 次失败即定胜负）。
  5. 连击奖励：按本次对抗内的拼点次数计算（含首投，与胜负平局无关），每 3 次令最终威力 +1，不封顶，对抗结束时一次性加到胜方身上。
  6. 对抗结束：胜方摧毁败方 1 枚行动币。

对抗胜利可以恢复理智值，连续胜利恢复更多；失败除了受伤还会降低理智。

单方面攻击 · 不进入拼点

满足任一即可：防守方 0 币且没有可用的【不可摧毁】守备手段； 防守方没有可用的守备技能；防守方处于【陷入混乱】【陷入恐慌】等无法应战的状态； 攻击方技能带【无法防御】。

反应（追击）

满足条件即可触发，不限于自己的回合。任何角色「攻击后」， 带【反应】词条的技能 / 装备若满足条件就能触发。反应相当于附赠动作。

回合结束时

所有目标行动完毕即视为回合结束：触发所有【回合结束时】效果，结算 BUFF，重投速度并重新排序。

可选规则 · 击退

拼点的激烈碰撞可以把目标击退：自己点数 10 / 20 / 30 分别击退 1 / 2 / 3 格，胜方可追击。 过程中若有目标撞上墙体，触发一次【震颤引爆】。

03.7陷入混乱 / 陷入恐慌

状态效果
陷入混乱 本回合无法行动也无法应战（被攻击时按单方面攻击结算），所有物理抗性强制调整为 ×2.0，行动币清零，回合结束时解除。跨过的那条阈值线会一直熄灭到长休
陷入恐慌 行动币清零，本回合仍可使用 E.G.O 技能发起对抗，回合结束时解除

03.8观察等级

面对未知威胁时，你看不到目标的具体数值和能力。通过「感知」侦测可以提升观察等级： 等级越高，越能看到目标的基础技能与弱点机制。观察等级足够高时可以解锁目标的机制， 用机制达成【强制混乱】。
