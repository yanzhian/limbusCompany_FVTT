## 序章

### 世界观

本次剧本发生在**都市的郊区**。

如果你玩过月亮计划旗下的作品，会更快进入状况；没玩过也不影响——你需要知道的只有一件事：这里没有首脑，没有秩序，只有活下去。

### 星引者（GM）

在郊区迷路时，抬头看看星空，它们会把你引入命运的河流。

作为 GM，你需要相对熟悉月计世界观，才能在这片贫瘠的土地上引导幸存者。你的职责是：设定鉴定难度、扮演 NPC、裁定规则边界，以及决定这群人什么时候该倒霉。

### 幸存者（PL）

都市之星图书馆事件之后，本该沉睡的你们在陌生的地域醒来。

打探一番后你们确认了处境：这里是都市外围的郊区，无人管辖，危机四伏。你们背景各异却目标一致——回到都市。于是你们在此搭起临时藏身处，搜集物资、结识本地 NPC，慢慢规划归途。

## 一、角色创建

创建一张角色卡要走六步：**选背景 → 分配属性 → 选恐慌卡 → 确认其他属性 → 学习技能 → 最后检查**。系统里由「创建向导」带着走。

### 1.1 选择背景

背景决定你**是谁**，也决定你开局拿到什么装备和技能书。详见背景表，排名不分先后。

| 大类 | 说明 |
|---|---|
| **幸存者** | 适合新手：忘记了身世，在废土上寻找自我。熟悉规则后可以换成剧本里遇见过的背景 |
| **世界之翼 / 巢** | H / K / L / N / P / R / T / W 公司，以及旧 L（脑叶公司分部）、旧 W（WARP 列车） |
| **帮派 / 五指** | 后巷的五大手指（拇指·食指·中指·环指·小指）与各帮派（黑云会、剑契组、布莱梅乐团、丧家犬） |
| **收尾人** | 十二协会 / 事务所 / 工坊 |

三点值得注意：

- **事务所**擅长团队协同，人多时能发挥出事务所特有的战斗风格。
- **工坊**拥有自己的制作表，可以给自己和队友打造本工坊的武器装备，并且**能多带传说装备**（一般角色只能装 1 件，工坊出身可以 3 件）。
- **协会**各有专精领域（暗杀、防御、决斗、情报……），会影响你被委托什么活。

### 1.2 分配属性

**总共 30 点，每项 2–8。**（系统 schema 允许到 10，创建阶段限制在 8。）

| 属性 | 影响 |
|---|---|
| 力量 Str | 攻击等级（力量÷3 向下取整）、采集建材的收获量 |
| 敏捷 Agi | 速度（1D6 + 敏捷）、移动步数、混乱阈值条数（>7 多一条） |
| 体质 Con | 防御等级（体质÷3 向下取整）、最大生命值、混乱阈值条数（>7 少一条） |
| 智力 Int | 恐慌鉴定的成功率、E.G.O 使用条件 |
| 感知 Per | 观察等级（侦察）、搜索战利品与物资箱的收获量 |
| 魅力 Cha | 交涉、NPC 谈判价格优惠 |

每 10 级获得 1 点属性点。

### 1.3 恐慌类型

对战中难免遇到不可名状之物：有些让人发疯，有些让人一蹶不振。建卡时要选**两张恐慌卡**——一张【士气低落】，一张【陷入恐慌】。

**基础恐惧**（示例）：

- **愤怒**：为自己添加 2 层【攻击等级提升】和 10 层【易损】
  *愤怒·坚定*：为自己本回合和下回合添加 2 层【强壮】
- **自残**：扣除自身 1D10 生命值，为自己添加 1 层 5 级【流血】
  *自残·坚定*：为自己添加 10 层【护盾】和 2 层【忍耐】

其余（无措 / 畏缩 / 怨恨 / 不洁 / 抑郁 / 徘徊 / 疯狂 / 迁怒 / 强迫）待补。

**特殊恐惧**：在遭遇郊区怪物或经历心理创伤后留下，若得不到治愈或长休会长期存在。

### 1.4 其他属性

- **容量**：初始 6×6，可以通过背包类「容器」扩充。
- **装备栏**：9 格。上装最多 1 件；下装 / 武器 / 饰品不限件数。已装备的物品可以在战斗中【激活】主动触发效果。
- **星芒**：上限 = `30 + 等级`（1 级为 31），每升 1 级 +1。装备技能和物品都要向星星许愿，星芒不足就装不上——这是对"全身稀有装备"的限制。
- **眼**：货币单位。都市的钱，郊区照用。

**星芒消耗表**

| | 消耗 |
|---|---|
| 技能 Lv.1 / Lv.2 / Lv.3 | 1 / 5 / 10 |
| E.G.O ZAYIN / TET / HE / WAW / ALEPH | 1 / 3 / 5 / 10 / 15 |
| 装备 | 默认 1，按装备描述调整 |

由【相关技能转换】产生的衍生技能不额外消耗星芒。

### 1.5 学习技能

- **背景技能**：选定背景会自动获得相关「技能书」。
- **技能书**：从战利品、NPC 授予或购买获得，能学到其他角色的技能。技能书学来的技能**无法精通**。
- **复制核心**：郊区最稀有的存在。持有它就能去「复制核心工作台」复制已经战胜过的目标，学会它的一个技能或获得它的一件物品。BOSS 与郊区怪物的技能基本只能通过这条路获得。
- **E.G.O 装备**：前 L 公司的奇点技术，心灵的具象化。装备后会自动学会对应的 E.G.O 技能。

### 1.6 完成建卡

填完之后你应该有：

- 一个背景与所属势力
- 分配好的六项属性
- 两张恐慌卡
- 势力给的装备与技能书
- 用技能书学到的 **6 个基础技能 + 1 个守备技能**

> 人类的赞歌是勇气的赞歌。不要对未知感到恐惧——在没有制度的郊区活下去，才是唯一的目标。

## 二、鉴定与生存

### 2.1 属性鉴定

1. GM 指定一项属性和一个**难度等级**。
2. 投掷**等同于你该属性数值**枚的十面骰（最少 2 枚；装备与扮演可以增减枚数）。
3. 每有一枚骰子结果**小于**你的属性值，算 1 次成功。
4. 成功次数 **≥** 难度等级即为成功。

参考难度：**1** 简单 / **2–3** 中等 / **4–5** 困难 / **6+** 极难。

### 2.2 事件鉴定

GM 给出一个事件和它的属性难度，玩家从事件提供的选项里挑一项做属性鉴定。成功与失败会导向不同结果。有些事件不需要鉴定，直接触发。

### 2.3 恐慌鉴定

理智值 **≤10** 时，每个回合结束会自动进行一次「智力」鉴定：投 1d10，结果 **≤ 智力**记【坚定 +1】，否则记【恐惧 +1】。

- 累计【坚定】3 次 → **坚定心智**，理智重置为 **70**
- 累计【恐惧】3 次 → **陷入恐慌**，理智重置为 **30**，触发恐慌卡效果

任一侧计满 3 点后，两侧计数在下一个回合开始时清空。

另外，理智值**首次**跌到 30 或以下时会触发【士气低落】，无需鉴定，一场遭遇战只触发一次。

### 2.4 威力鉴定

面对可破坏的物体（门窗、巨石等），可以在破坏前用「技能」进行鉴定。中途可以无限尝试，直到物体被破坏或触发其他事件。

### 2.5 营地与制作台

营地是你们的家。建筑不止一个，各有各的容量和配方。

| 建筑 | 初始容量 | 用途 |
|---|---|---|
| 制作台 | 8×8 | 最基础的工作台，随等级解锁更多配方与建筑 |
| 熔炉 | 6×6 | 原矿的归宿 |
| 武器 / 弹药制作台 | 6×6 | 首脑管不到郊区，弹药是廉价硬通货 |
| 灶台 | 6×6 | 出发前的热饭与长途口粮 |
| 医疗制作台 | 6×6 | 一根针、一瓶安瓿、一口丸，都可能逆转战局 |
| 情报信息台 | 6×6 | 想离开郊区，情报比勇气和运气更重要 |
| 复制核心复刻机 | 6×8 | 郊区的失落奇迹 |
| 拟态物健身房 | — | 休息时别让身体生疏（会骨折的那种） |

**配方表**是一种可以拾取和交易的物品：把它放进营地建筑里**双击或右键**即可使用，其中的配方会被永久追加到该建筑的配方列表，配方表本体随之消耗。如果里面的配方该建筑已经全部拥有，则不会消耗——留着当纪念。

点击【制作】时可以选择产物去向：**营地仓库**或**制作者的背包**。仓库放不下时自动改放进制作者背包；可堆叠的产物会与已有的同名物品合并。

**容器**用来管理物资，不同箱子容量与用途不同：

| 容器 | 自身大小 | 内部容量 | 限制 |
|---|---|---|---|
| 木箱 | 3×4 | 8×8（可升级：Lv.2 8×10 / Lv.3 10×12） | 无 |
| 冷冻箱 | 2×2 | 6×6 | 只放食材，不可升级 |
| 建材箱 | 3×2 | 8×10 | 只放建材，不可升级 |
| 医疗箱 | 2×2 | 6×6 | 只放消耗品 / 医疗，不可升级 |
| 档案箱 | 2×2 | 6×8 | 只放档案，不可升级 |
| 装备收藏展示箱 | 2×3 | 8×10 | 只放装备 / 武器，不可升级 |

### 2.6 郊区的中立交易生物

有些郊区生物愿意和人类做交易。下次见到它们，也许能帮上忙。

- **圣诞精灵**（12 区）：对人类极具敌意，但有那么几个例外。掉落的装备或者太大带不走的东西，贴上礼物标记，它们会做成礼物送到你的营地——收费是人类尸块。
- **旅行沙虫**：实在撤不下来时的最下策，用人类尸体交易，让它把你平安送回营地。它似乎不喜欢鲜活的人类，反而偏好腐烂发臭的，下次搜刮时看到尸体不妨顺手带上。
- **拟态物**：只会拙劣模仿人类和怪物的动作，攻击性强但伤害不高，适合练手。

### 2.7 搜刮与采集

| 行为 | 鉴定 | 收获 |
|---|---|---|
| 搜索物资箱 | 感知 | 每成功 1 次，从物资表随机抽取一个物品 |
| 采集资源 | 力量（需要对应工具：砍树用斧、挖矿用镐） | 获得等同于成功次数的数量 |
| 搜刮尸体 | 敏捷 或 感知 | 按战利品表 |
| 截肢 / 取部位 | 力量（需要工具） | 按战利品表 |

## 三、战斗

### 3.1 简介

整体框架接近边狱巴士，但做了两处关键改动：**技能槽换成了行动币**，**硬币换成了随机性更大的骰子**。

如果你已经熟悉边狱巴士，只需要读 [3.4 装备与消耗品](#34-装备与消耗品) 和 [3.5 行动时点](#35-行动时点)。

### 3.2 基础属性

**攻击等级** = `力量 ÷ 3（向下取整）+ 等级`，再由装备修正。
**防御等级** = `体质 ÷ 3（向下取整）+ 等级`，再由装备修正。

- 双方都是攻击时，比较双方的攻击等级；一方攻击一方守备时，比较攻击等级与防御等级。**每相差 3 级，最终骰数 +1。**
- 防御等级只在伤害结算或使用守备技能时生效。
- 不存在双方都是守备的情况。

**速度** = `1D6 + 敏捷`，决定先攻顺序，同时决定本回合可移动的格数（速度 ÷ 5）。

**生命值** = `基础值 + (等级 - 1) × 成长值`，两者都由体质决定：体质 1 → 基础 60 / 每级 +2.0，体质 8 → 基础 80 / 每级 +3.0，中间按比例取值。长休恢复至最大值。

**理智值**：初始 50，范围 5–95。使用 E.G.O 技能、拼点失败都会降低；拼点胜利、长休 / 短休（固定回到 50）可以恢复。

**混乱阈值**：默认 2 条，位于最大生命值的 **60% / 30%**；体质 > 7 减为 1 条（50%），敏捷 > 7 增为 3 条（80% / 50% / 20%）。生命值掉过某一条就会【陷入混乱】，该条随即熄灭直到长休；一次掉血事件最多触发一条（由高到低检查）。【震颤引爆】会把所有阈值百分比永久前移，可叠加，同样在长休时重置。

**物理抗性**：分【斩击】【打击】【突刺】，默认 ×1.0，由【上装】修改。
**罪孽抗性**：七种，默认 ×1.0，由使用的 E.G.O 技能修改。

**罪孽资源**：公共资源，共 7 种。使用技能后会为对应罪孽增加 1 点。
**场地资源**：公共资源，背景专用效果（例如【拉曼却】【血魔】背景的「血宴」）。

### 3.3 行动币（AP）

这是本作和原作差别最大的地方，值得单独一节。

**行动币没有上限**，可以由技能 / 装备 / 消耗品提升。回合开始时不足 3 枚的补满至 3 枚，已经超过 3 枚的**保留**，不削减也不负债。

**使用技能不消耗行动币**，发起对抗也不消耗——这是一场有胜算才出手的游戏。

行动币是**容量，不是消耗品**：你的币数 = 本次对抗里**允许失败几次**，拼点过程中一枚都不会扣。对抗结束时，胜方摧毁败方 1 枚（每次对抗至多 1 枚；败方用的是【不可摧毁】骰时不摧毁；已经 0 枚则无事发生）。

0 枚行动币**不代表不能防守**：仍然可以应战，只是拼点威力额外 **-3**，且输一次就直接定胜负。

> 例：A 有 5 币 → 对抗失败被摧毁 1 → 4 币 → 队友技能回 2 → 6 币 → 下次对抗从"允许失败 6 次"开始 → 又失败被摧毁 1 → 5 币 → 下个回合因为已经 ≥3 币，不再补满。

### 3.4 技能

**基础技能**（最多装备 6 个）
物理类型：斩击 / 打击 / 突刺。罪孽类型：暴怒 / 色欲 / 怠惰 / 暴食 / 忧郁 / 傲慢 / 嫉妒。技能等级 Lv.1–3。主要输出手段。

**守备技能**（装备 1 个）
类型：闪避 / 格挡 / 反击 / 可拼点格挡 / 可拼点反击。

| 守备类型 | 效果 |
|---|---|
| 闪避 | 双方同时出手，只拼一次；不消耗行动点也不碎币。**平局算闪避成功** |
| 格挡 | 直接受到伤害，减少等同于自己格挡骰数的伤害 |
| 反击 | 直接受到伤害，同时对目标造成自己骰数的伤害 |
| 可拼点格挡 | 拼点成功 → 无视本次伤害；失败 → 受伤并减免自己格挡骰数 |
| 可拼点反击 | 拼点成功 → 对目标造成自己骰数的伤害；失败 → 受伤并仍然反击 |

守备技能**无法主动发起对抗**，只能在被【发起对抗】时选用；在战斗页只能【激活】。

**E.G.O 技能**
需要消耗**罪孽资源**和**理智值**。可以通过技能书和 E.G.O 饰品学习。每个 E.G.O 等级只能装备 1 个。使用后会修改自己的罪孽抗性。

角色【陷入恐慌】时，所有 E.G.O 技能强制切换为**侵蚀形态**，直到脱离恐慌为止。

### 3.5 一张卡的多套数值

同一张技能卡可以挂多套数值，切换的是"当前用哪一套"，而不是换一张卡。两套机制互斥：

| 机制 | 适用 | 切换方式 |
|---|---|---|
| **觉醒 / 侵蚀** | 仅 E.G.O | 【陷入恐慌】时强制切到侵蚀 |
| **训练等级 Ⅲ→Ⅳ→Ⅴ** | 仅基础 / 守备 | 每 3 级获得一次强化名额，在升级时自选 |

**训练等级**：默认 Ⅲ 级，精通 Ⅳ 级，强化 Ⅴ 级；数据上 Ⅰ～Ⅴ 五阶都可用，Ⅰ / Ⅱ 留给低于「默认」的残缺版本或试作品。切换训练等级**不会改变**：名称 / 类型 / 分类 / 罪孽 / 等级 / 标签；其余（骰式、骰子类型、反击分类、攻击容量与扩散、各种标记、理智消耗、星芒、武器限制、描述、激活效果）每一阶各有一套。

强化名额落在 Lv3 / 6 / 9 / … / 48，满级 50 共 16 次。可选的不限于已装备的 7 个技能——技能列表里没装上去的同样能挑。

### 3.6 装备与消耗品

| 部位 | 修改 | 限制 |
|---|---|---|
| 上装 | 防御等级、物理抗性 | 只能装 1 件 |
| 下装 | 防御等级、速度 | 不限 |
| 武器 | 攻击等级、防御等级、速度 | 不限 |
| 饰品 | 攻击等级、防御等级、速度 | 不限 |

带效果的装备可以【激活】触发，**消耗 1 行动币**。

**消耗品**：战斗中每回合只能使用 1 次，**不消耗行动币**。
**背包**：背包里的物品在战斗中既不能激活也不能使用，只能战前准备时与身上的替换。
**传说装备**：占用大量星芒并配套专属技能。只能装备 1 件——工坊背景可以装 3 件。

### 3.7 行动时点

**回合开始时**
1. 所有角色重投「速度」决定先后顺序
2. 行动币不足 3 枚的补满至 3 枚（超过的保留）；恐慌 / 坚定计数若已计满 3 点则清空
3. 触发所有【回合开始时】的技能与装备效果
4. 从本轮第一位开始行动

**角色行动**
- 可以移动「速度 ÷ 5」格
- 可以【激活】装备 / 消耗品 / 守备技能，每次消耗 1 行动币（消耗品不消耗）
- 对范围内的 1 个目标使用【基础技能】或【E.G.O 技能】——这视为**发起对抗**
- 使用技能后，或主动结束，本次行动结束

**对抗（拼点）**

如果技能的目标是你，且你还有行动币，可以选择用基础技能 / 守备技能 / E.G.O 技能应战。进入对抗后双方比较【拼点威力】，胜方对败方造成全部骰数的伤害。

1. **第一次投掷免费**：攻守双方各投一次
2. **输一次** → 双方重掷再拼一次，并占用输方 1 次「失败次数」（上限 = 输方的行动币数）
   - 一般骰：每失败一次，输方本次对抗内的拼点威力累计 **-1**（第 1 次 -1，第 2 次 -2，以此类推）
   - 【不可摧毁】骰：同样占用失败次数，但**不吃惩罚**，也不会在对抗结束时被摧毁
   - 该惩罚只影响拼点胜负，**不影响最终伤害**，对抗一结束即清空
3. **平局** → 不分胜负、不占用失败次数、不加惩罚，双方重掷再拼
4. **失败次数用满** → 彻底失败（3 币 = 允许失败 3 次，第 4 次失败即定胜负）
5. **连击奖励**：按本次对抗内的**拼点次数**计算（含第一次免费投掷，与胜负平局无关），每 3 次令最终威力 **+1**，不封顶，对抗结束时一次性加到胜方身上
6. **对抗结束**：胜方摧毁败方 1 枚行动币

对抗胜利可以恢复理智值，连续胜利恢复更多；失败除了受伤还会降低理智。

**单方面攻击**（不进入拼点，直接结算伤害）满足任一即可：

- 防守方 0 币且没有可用的【不可摧毁】守备手段
- 防守方没有可用的守备技能
- 防守方处于【陷入混乱】【陷入恐慌】等无法应战的状态
- 攻击方技能带【无法防御】

**承受伤害**
拼点失败或单方面受击后进入伤害结算，按物理抗性、罪孽抗性和自身 BUFF 算出最终伤害。若伤害跨过混乱阈值，接着进入【陷入混乱】。

**反应（追击）**
满足条件即可触发，**不限于自己的回合**。任何角色「攻击后」，带【反应】词条的技能 / 装备若满足条件就能触发。反应相当于附赠动作。

**回合结束时**
所有目标行动完毕即视为回合结束：触发所有【回合结束时】效果，结算 BUFF，重投速度并重新排序。

**击退（可选规则）**
拼点的激烈碰撞可以把目标击退：自己点数 10 / 20 / 30 分别击退 1 / 2 / 3 格，胜方可追击。过程中若有目标撞上墙体，触发一次【震颤引爆】。

### 3.8 陷入混乱 / 陷入恐慌

**陷入混乱**：本回合无法行动也无法应战（被攻击时按单方面攻击结算），所有物理抗性强制调整为 **×2.0**，行动币清零，回合结束时解除。跨过的那条阈值线会一直熄灭到长休。

**陷入恐慌**：行动币清零，本回合**仍可使用 E.G.O 技能发起对抗**，回合结束时解除。

### 3.9 观察等级

面对未知威胁时，你看不到目标的具体数值和能力。通过「感知」侦测可以提升观察等级：等级越高，越能看到目标的基础技能与弱点机制。观察等级足够高时可以解锁目标的**机制**，用机制达成【强制混乱】。

## 四、状态（BUFF）一览

每个 BUFF 附加时默认有 1 层。**强度**只有特殊 BUFF 才有（例如"12 强度 2 层的烧伤"，左强度右层数）。层数与强度都可叠加；层数归 0 即清除。

### 增益

| 状态 | 效果 |
|---|---|
| 强壮 | 本回合内「攻击类」技能的最终威力 + 层数 |
| 忍耐 | 本回合内「守备」技能的最终威力 + 层数 |
| 迅捷 | 本回合内速度的最大 / 最小值 + 层数 |
| 守护 | 本回合内受到的伤害 − 层数 |
| 拼点威力提升 | 本回合内进行拼点时，拼点威力 + 层数 |
| 攻击 / 防御等级提升 | 本回合内攻击 / 防御等级 + 层数 |

### 减益

| 状态 | 效果 |
|---|---|
| 虚弱 | 本回合内「攻击类」技能的最终威力 − 层数 |
| 破绽 | 本回合内「守备」技能的最终威力 − 层数 |
| 束缚 | 本回合内速度的最大 / 最小值 − 层数 |
| 易损 | 本回合内受到的伤害 + 层数 |
| 拼点威力降低 | 本回合内进行拼点时，拼点威力 − 层数 |
| 攻击 / 防御等级降低 | 本回合内攻击 / 防御等级 − 层数 |

### 特殊

| 状态 | 效果 |
|---|---|
| 烧伤 | [回合结束时] 减少 1 层，受到等同强度的固定伤害 |
| 流血 | [攻击时] 减少 1 层，受到等同强度的固定伤害 |
| 破裂 | [受到伤害时] 减少 1 层，额外受到等同强度的固定伤害 |
| 沉沦 | [受到伤害时] 减少 1 层，额外受到等同强度的理智伤害（侵蚀度）；若理智因此跌到下限 5，再额外受到同等强度的【忧郁】伤害 |
| 震颤 | 受到造成【震颤引爆】的攻击时，混乱阈值前移等同强度的数值；层数归 0 即消失 |
| 呼吸法 | 下次造成伤害时有「强度 × 5%」的概率产生暴击 |
| 充能 | 特定技能所需的资源，最大 20 层，回合结束时减少 1 层 |
