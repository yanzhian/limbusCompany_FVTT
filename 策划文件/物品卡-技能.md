## 一、技能类型一览

技能分为三种类型，物品卡结构大体相同，部分字段因类型而异：

| 字段 | 基础技能 | 守备技能 | E.G.O技能 |
|------|---------|---------|----------|
| 攻击/守备类型图标 | 斩击/打击/突刺 | 闪避/格挡/反击/可拼点格挡/可拼点反击 | 斩击/打击/突刺 |
| 攻击容量 | ✓ | ✗ | ✓ |
| 消耗（罪孽资源） | ✗ | ✗ | ✓ |
| 修正（罪孽抗性） | ✗ | ✗ | ✓ |
| 相关技能【+】 | ✓ | ✓ | ✓ |
| 发起对抗按钮 | ✓ | ✓ | ✓ |

## 二、攻击/守备类型图标

第二行左侧图标代表技能的攻击或守备分类，**不是罪孽图标**：

| 图标 | 类型 | 适用 |
|------|------|------|
| Slash.webp | 斩击 Slash | 基础技能 / EGO技能 |
| Blunt.webp| 打击 Blunt | 基础技能 / EGO技能 |

| 反击.webp | 反击 | 守备技能 |

## 三、攻击容量说明

- **攻击容量**：命中后可额外选择目标受到伤害的数量
- 黄色小方块图标，数量即为攻击容量数值（如：1个方块 = 攻击容量1，4个方块 = 攻击容量4）
- **守备技能无攻击容量字段**

## 四、物品卡-技能（锁定状态）

### 整体布局（从上到下）

**标题栏**
- 左侧：🔒 图标 + 【技能】文字
- 右侧：× 关闭按钮

**第一行：基本信息**
- 左：技能图标（六边形边框，颜色对应罪孽属性色）
- 中：技能名字
- 右上角：【+】按钮，点击展开/折叠相关技能（见第六节）

**第二行：类型与公式**
- 左：攻击/守备类型图标
- 右：骰子公式（如：`1D4+2`）

**第三行：标签**
- 标签胶囊横向排列，如：`标签1` `标签2`

**E.G.O技能专有行（基础/守备技能无此行）**
- 消耗：罪孽资源图标 + 数值，可多种，如：🍇 3  🟠 1
- 攻击容量：黄色小方块（E.G.O技能可有多个）
- 修正（罪孽抗性）：使用后修改的罪孽抗性，如：🍃×0.5  💧×2

**基础技能专有行**
- 攻击容量：黄色小方块（通常1个）

**描述区**
- 深棕色背景文本框，显示技能效果描述

**底部按钮栏**

| 按钮 | 功能 |
|------|------|
| 发送聊天框 | 向聊天发送该技能的展示卡片 |
| 发起对抗 | 以该技能发起对抗（见对抗.md） |
| 编辑激活效果 | 展开激活效果编辑区（见第五节） |

**底部右侧**
- ☆ + 星芒消耗数字

## 五、编辑激活效果区

点击【编辑激活效果】后，卡片下方展开效果列表区域（▲/▼ 折叠/展开）。

- 每条效果显示：效果名称 + 【编辑】按钮 + 【删除】按钮
- 底部：【添加效果】按钮，点击弹出效果触发编辑器
- 效果触发编辑器字段与装备完全一致，参考 `物品卡-装备.md` 第六节

---

## 六、相关技能扩展（点击【+】展开）

- 主技能卡片正常显示于上方
- 点击【+】后，下方分割线后展开**相关技能卡片**
- 相关技能卡片结构与主技能完全相同（名字/类型图标+公式/标签/攻击容量/描述/三个按钮）
- 相关技能图标边框为**绿色**（区别于主技能的罪孽属性色）
- 整张卡片底部右侧只有一个 ☆ 星芒数字（主技能与相关技能共用）
- 相关技能不消耗星芒（星芒由主技能统一计算）

## 七、物品卡-技能（解锁编辑状态）

点击 🔒 图标解锁，进入编辑模式，🔒 变为 🔓。

### 可编辑字段（从上到下）

**名称**
- 文本输入框，编辑技能名称

**分类 + 骰数**
- 分类：下拉菜单，选项如下：
  - 基础/EGO技能：斩击 / 打击 / 突刺
  - 守备技能：闪避 / 格挡 / 反击 / 可拼点格挡 / 可拼点反击
- 骰数：文本输入框，如：`1D4+2`

**标签**
- 文本输入框，格式：`标签1/标签2`

**攻击容量**
- 数字输入框（如：`1`）
- 守备技能无此字段

**消耗**（仅 E.G.O 技能）
- 下拉罪孽类型图标 + 数值输入框
- 【+】按钮：添加更多消耗条目（多种罪孽资源）

**修正**（仅 E.G.O 技能）
- 下拉罪孽抗性图标 + 数值输入框
- 【+】按钮：添加更多修正条目

**描述**
- 富文本编辑器，带格式工具栏

**编辑激活效果区**
- 同锁定状态，点击【编辑激活效果】展开
- 效果列表：名称1 / 名称2 + 【编辑】【删除】
- 底部：【添加效果】按钮

**底部右侧**
- ☆ 星芒数字可直接点击修改

## 八、BUFF下拉框选项（效果触发编辑器内）

| 分组 | 选项 |
|------|------|
| 增益 | 强壮 / 忍耐 / 迅捷 / 守护 / 拼点威力提升 / 攻击等级提升 / 防御等级提升 |
| 减益 | 虚弱 / 破绽 / 束缚 / 易损 / 拼点威力降低 / 攻击等级降低 / 防御等级降低 |
| 特殊 | 烧伤 / 流血 / 震颤 /破裂 / 沉沦 / 呼吸法 / 充能 / 陷入混乱 / 陷入恐慌 |
| 其他 | 自定义 |

> 选择【自定义】时显示自定义BUFF文本输入框。
> 下拉框通用样式：选中项高亮棕色背景，其余暗色。
