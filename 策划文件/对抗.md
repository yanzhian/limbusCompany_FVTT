# 对抗流程设计文档
**边狱巴士都市规则 · FVTT v13+**
版本：1.0 | 格式：Markdown

---

## 一、流程总览

```
玩家A 发起对抗
    ↓
聊天框显示技能卡片，目标玩家B 选择【对抗】或【承受】
    ↓
        ┌─── 【对抗】→ 双方各自在确认框选择技能 → 拼点结算聊天框 → 【承受】扣血
        └─── 【承受】→ 直接进入承受结算聊天框 → 扣血
```

---

## 二、发起对抗

### 触发方式
- 战斗页面技能格子点击 **▶ 发起对抗**
- 右键技能格子 → 菜单选择【发起对抗】

### 发起对抗确认框弹窗

| 元素 | 内容 |
|------|------|
| 标题 | 发起对抗，右上角 × 关闭 |
| 技能名 | 当前选中技能名称 |
| 骰子公式 | 罪孽图标 + 公式，如：`1D4+2` |
| 加值修正 | 输入框，占位文字【加值修正?】，输入 `+N` 增加 / `-N` 减少 |
| 确认按钮 | 宽大深棕色按钮【发起对抗】，点击后向聊天框发送对抗消息 |

---

## 三、聊天框 — 发起对抗消息（玩家A发出）

所有玩家可见，目标玩家需在此消息上做出响应。

### 布局

| 区域 | 内容 |
|------|------|
| 顶部 | 左上角圆形头像 + 【发起对抗】标题 + 玩家姓名小字 |
| 技能卡片 | 八边形技能格子图标（大）+ 右侧技能名称 + 骰子公式 |
| 效果描述 | 技能触发时机与效果文本，如：`[攻击时] 下回合为自己添加 1 层 🍃 呼吸` |
| 底部按钮 | 【对抗】深棕色 / 【承受】红色，并排显示 |

---

## 四、对抗确认框（通用）

**发起者和对抗者看到的确认框完全相同**，唯一修改的为
| 确认按钮 | 宽大深棕色按钮【进行对抗】，点击后向聊天框发送对抗消息 |

### 默认状态（折叠）

顶部固定显示3格，优先级排列：

| 格子位置 | 内容 |
|---------|------|
| 第1格 | 当前【激活】技能（6-bag 抽出，槽位1） |
| 第2格 | 当前【激活】技能（6-bag 抽出，槽位2） |
| 第3格 | 当前装备的【守备技能】 |

- 底部显示 **▼** 箭头，点击展开完整技能列表

### 展开状态

点击 ▼ 后展开，▼ 变为 **▲**，显示所有可选技能槽：

| 区域 | 内容 |
|------|------|
| 顶部3格（同上） | 激活1 / 激活2 / 守备技能 |
| 分割线 + ▲ | 点击折叠 |
| 基础技能区（5格） | 3×2 排列，八边形格子 |
| EGO技能区（5格） | 横向排列，圆形格子，底部显示等级标签（ZAYIN/TET/HE/WAW/ALEPH） |

### 选择逻辑

- 点击任意格子 = 选中该技能参与本次对抗
- 选中后确认框关闭，进入拼点计算
- 未装备的空格子不可选中

---

## 五、聊天框 — 进行对抗消息（玩家B响应后）

玩家B选择【对抗】并选定技能后，聊天框发出拼点消息。

### 布局

| 区域 | 内容 |
|------|------|
| 顶部 | 左上角圆形头像 + 【进行对抗】标题 + 玩家姓名小字 |
| 技能展示 | 八边形格子图标（大）+ 右侧技能名称 + 骰子公式 |
| 对抗按钮 | 【对抗】深棕色按钮（已选择状态） |
| 效果描述 | 技能触发时机与效果文本 |

---

## 六、聊天框 — 拼点结算消息

双方技能选定后自动结算，向聊天框发出结算消息。

### 布局

| 区域 | 内容 |
|------|------|
| 顶部 | 左上角圆形头像 + 【拼点对抗】标题 + 玩家姓名小字 |
| 技能对比区 | 左：玩家A技能图标 + 技能名 + 骰子公式 |
| | 中：**VS** 大字 |
| | 右：玩家B技能图标 + 技能名 + 骰子公式 |
| 拼点结算 | 文字【拼点结算】+ 左边数值 `>` 右边数值（败方数值显示为红色） |
| 结算说明 | 多行文字，如：`本次对抗：玩家1 vs 玩家2` / `玩家1 获胜 玩家2 败北` / 特殊状态触发说明（如：`由于 玩家2 斩击弱性 伤害翻倍`）/ `玩家2 受到 10 点伤害` ，详细参考 特殊状态触发说明|
| 底部按钮 | 【承受】按钮，提示文字：`先选中 Token，再点击按钮扣除 N 点生命值` |

---

## 七、聊天框 — 承受结算消息

点击【承受】按钮后（无论是直接承受还是拼点后承受），发出结算消息。

**背景色：深红色**

### 布局

| 区域 | 内容 |
|------|------|
| 顶部 | 左上角圆形头像 + 【承受】标题 + 玩家姓名小字 |
| 标题 | 居中大字【生命值结算】 |
| 伤害说明 | `玩家X 受到 N 点伤害` |
| HP变化 | 大字显示：旧HP **→** 新HP |
| 混乱阈值触发 | （若触发）提示文字：`伤害超过混乱阈值 陷入混乱` + 红色HP条（当前HP / 最大HP） |

---

## 八、承受（直接承受，跳过拼点）

玩家B在发起对抗消息上点击【承受】，直接跳过拼点，进入承受结算。

- 伤害数值 = 玩家A骰子公式的结果
- 直接发出承受结算消息（第七节）
- 不经过拼点结算消息

---

## 九、特殊状态触发说明

拼点结算消息中，若触发以下情况需在结算说明中附加文字：

| 情况 | 附加说明示例 |
|------|------------|
| 目标斩击弱性（混乱状态） | `由于 玩家2 斩击弱性 伤害翻倍` |
| 混乱阈值触发 | `伤害超过混乱阈值 陷入混乱` |
| 暴击 | `暴击！伤害×2` |
| 其他BUFF/DEBUFF触发 | 根据 Activity 触发器动态生成文字 |
