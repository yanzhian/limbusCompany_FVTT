## 二、物品卡-材料

### 锁定状态

**标题栏**
- 左侧：🔒 图标 + 【材料】文字
- 右侧：× 关闭按钮

**第一行：基本信息**
- 左：物品图标
- 中：材料名字
- 右：`× 数量`（如：× 10）

**第二行：类型与分类**
- 格式：`材料　分类`（如：`材料　树枝`）

**标签**
- 标签胶囊横向排列，如：`标签1` `标签2`

**描述区**
- 深棕色背景文本框，显示材料描述

**底部按钮**
- 【发送聊天框】— 唯一按钮

> 材料无【使用】按钮、无【编辑激活效果】、无星芒消耗。

---

### 解锁编辑状态

🔒 变为 🔓，标题变为【材料/消耗品】（与消耗品共用编辑界面）。

| 字段 | 类型 | 说明 |
|------|------|------|
| 名称 | 文本输入框 | 编辑材料名称 |
| 数量 | 数字输入框 | `× N` 右侧 |
| 类型 | 文本输入框 | 如：材料 |
| 分类 | 文本输入框 | 如：树枝 |
| 标签 | 文本输入框 | 格式：`标签1/标签2` |
| 描述 | 富文本编辑器 | 带格式工具栏 |

## 三、物品卡-消耗品

### 锁定状态

**标题栏**
- 左侧：🔒 图标 + 【消耗品】文字
- 右侧：× 关闭按钮

**第一行：基本信息**
- 左：物品图标
- 中：消耗品名字
- 右：`× 数量`（如：× 10）

**第二行：类型与分类**
- 格式：`消耗品　分类`（如：`消耗品　药水`）

**标签**
- 标签胶囊横向排列，如：`标签1` `标签2`

**描述区**
- 深棕色背景文本框，显示消耗品效果描述

**底部按钮栏**

| 按钮 | 功能 |
|------|------|
| 发送聊天框 | 向聊天发送该消耗品展示卡片 |
| 使用 | 使用该消耗品，数量 -1，触发效果 |
| 编辑激活效果 | 展开激活效果编辑区（见下方） |

> 消耗品无星芒消耗。

**编辑激活效果区**
- 点击【编辑激活效果】展开，▲/▼ 折叠/展开
- 每条效果：效果名称 + 【编辑】+ 【删除】
- 底部：【添加效果】按钮
- 效果触发编辑器字段与装备完全一致，参考 `物品卡-装备.md` 第六节

---

### 解锁编辑状态

与材料共用同一编辑界面，🔒 变为 🔓，标题为【材料/消耗品】。

| 字段 | 类型 | 说明 |
|------|------|------|
| 名称 | 文本输入框 | 编辑消耗品名称 |
| 数量 | 数字输入框 | `× N` 右侧 |
| 类型 | 文本输入框 | 如：消耗品 |
| 分类 | 文本输入框 | 如：药水 |
| 标签 | 文本输入框 | 格式：`标签1/标签2` |
| 描述 | 富文本编辑器 | 带格式工具栏 |
| 编辑激活效果区 | — | 展开后显示效果列表 + 【添加效果】 |
