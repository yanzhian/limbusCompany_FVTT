## 二、顶部区域 — 三列布局

Tab 页签以上全部属于顶部区域，分为三列并排：

| 列 | 上半部分 | 下半部分 |
|----|---------|---------|
| 左列（~275px） | A：头像 275×275px（含LV/经验） | B：生命值行 + 理智值行 |
| 中列 | 基础信息栏（攻击/防御/速度） | 抗性信息栏（斩击/打击/突刺倍率） |
| 右列 | 背景标签 + 玩家名字 + 长休按钮 | 六属性 + 鉴定圆圈 |

---

## 三、各区域详细规格

### 区域 A：头像（左列上半）

| 元素 | 规格 |
|------|------|
| 头像图片 | 55×55px，可点击更换 |
| 编辑锁 | 左上角（✎图标），锁定时禁止编辑：六属性 / 名字 / 背景 / 等级 / 经验 / 眼（货币）/ HP / 理智 |
| LV等级 | 头像内右侧，【LV】小字 + 等级数字大字加粗，如【LV 1】 |
| 经验值 | 等级下方，格式：当前XP / 下级XP，如【4/10】 |
| 经验进度条 | 经验值下方，细长进度条显示升级进度 |

---

### 区域 B：生命值 & 理智值（左列下半）

位于头像正下方，同列上下排列两行。

**❤ 生命值行**
- 构成：❤图标 + 当前HP/最大HP + 血条 + 重置按钮（↺）
- 混乱阈值刻度叠加在血条上，白色细竖线，位置 = 最大HP × 阈值%
- 触发过的阈值刻度变灰/消失（`triggered = true`）
- 震颤引爆后阈值位置动态前移

**🧠 理智值行**
- 构成：🧠图标 + 当前理智/95 + 理智条 + 重置按钮（↺）
- 渐变色：高 → 蓝色，中 → 灰色，低 → 红色（三段渐变）
- 理智 ≤ 5 时条变全红并标注【陷入恐慌】

---

### 区域 C：基础信息栏 & 抗性信息栏（中列）

> 两栏均为只读展示，系统根据装备自动计算，不可手动修改。

**基础信息栏（上）**
- ⚔ 攻击等级调整
- 🛡 防御等级调整
- 🥾 速度范围（最小值-最大值）

**抗性信息栏（下）**
- 斩击 × N / 打击 × N / 突刺 × N
- 由当前装备的【上装】决定，默认全部 ×1.0

---

### 区域 D：背景标签 & 玩家名字 & 长休（右列上半）

- **背景标签**：右上角小胶囊，显示背景分类（如：背景-收尾人-7阶）
- **玩家名字**：大字加粗，编辑锁关闭时可编辑
- **长休按钮**：名字左侧金色胶囊按钮，触发长休逻辑（HP / 理智 / 混乱阈值 / AP 全重置），**无需确认对话框，直接执行**

---

### 区域 E：六属性 & 鉴定（右列下半）

- 6个属性横向排列：力量 / 敏捷 / 体质 / 感知 / 智力 / 魅力
- 每个属性：属性名小字 + 属性值大字
- 每个属性下方有圆圈按钮，点击触发对应属性的【鉴定界面】

## 五、装备栏（Tab-物品，左侧）

- 3×3 九宫格，默认全空，格子显示深棕色占位样式
- 可从物品列表或物品卡拖入装备
- **星芒不足时**：拒绝放置，显示黄色警告提示，无法放入格中
- **悬停任何已装备图标**：显示 Title 卡片（详见第七节）
- 装备格链接箭头：相邻格链接方向对齐时高亮显示【相互链接】

**已装备物品交互**

| 操作 | 行为 |
|------|------|
| 左键单击 | 聊天框发送物品信息 |
| 右键 | 弹出菜单：【卸下】【查看/编辑】【激活】 |
| 悬停 | 显示 Title 卡片 |

## 六、物品列表（Tab-物品，右侧）

### 工具栏（搜索栏左侧，从左到右）

| 按钮 | 功能 |
|------|------|
| ★ | 收藏筛选（只显示已收藏物品） |
| ▽ | 过滤面板（见下方过滤规格） |
| ⊞/⊟ | 全部展开 / 全部折叠 |
| ≡ | 列表布局（本期实现） |
| ＋ | 新建物品 |

> 图标布局暂不制作。

### 过滤面板规格

点击【▽过滤】按钮后弹出浮层面板，点击外部区域关闭，关闭时保留已选状态。

**分类过滤**
- 7个标签按钮横向排列（自动换行）：武器 / 饰品 / 上装 / 下装 / 消耗品 / 材料 / 容器
- 支持多选；点击已选标签可取消；选中高亮（金色/棕黄色）
- 分类内部为 OR 关系（武器 OR 饰品）

**链接方向过滤**
- 十字形布局四方向按钮（↑ ↓ ← →），支持多选
- 选中方向后只显示装备链接中包含该方向的物品
- 多方向之间为 OR 关系

**过滤逻辑**
- 不同维度（分类 × 链接方向）之间为 AND 关系

**确认**
- 底部【过滤】按钮，点击应用所有条件并关闭浮层

### 列表布局规格

- 按类型分组（武器 / 上装 / 下装 / 饰品 / 消耗品 / 材料 / 容器）
- 行高固定 18px

| 列 | 宽度参考 | 内容 |
|----|---------|------|

| 名称 | 自适应 | 物品名 |
| 分类 | 80px | 如：匕首、盔甲 |
| 链接 | 60px | 链接方向箭头（仅装备类） |
| 数量 | 50px | 数字 |
| 星芒 | 50px | 消耗的星芒点数 |
| 操作 | 80px | ▶激活 / ⋮更多 / ★收藏 |

## 九、鉴定界面规格

### 鉴定弹窗

| 元素 | 规格 |
|------|------|
| 标题栏 | 居中显示【属性名鉴定】，如：力量鉴定；右上角关闭按钮 × |
| 难度等级 | 标签【难度等级】+ 8枚硬币横向排列 |
| 硬币交互 | 点击第N枚 → 第1\~N枚全变正面，第N+1\~8枚全变反面（一键设定难度N） |
| 硬币正面 | 金色八边形硬币图标（亮色/有光泽） |
| 硬币反面 | 同形状，暗色/哑光 |
| 加值修正 | 输入框，输入 `+N` 增加N枚硬币，输入 `-N` 减少N枚硬币，调整实际投掷总数 |
| 鉴定按钮 | 宽大深棕色按钮，居中文字【鉴定】，点击后向聊天框发送结果 |

### 鉴定聊天框 — 三种结果

| 结果 | 背景色 | 结果大字颜色 | 触发条件 |
|------|--------|-------------|---------|
| 成功 | 深棕/暗色 | 金色 | 正面数 ≥ 难度，且正面数 ≠ 难度 |
| 完美成功 | 深棕/暗色 | 金色（更亮/更大） | 正面数 = 难度（精确相等） |
| 失败 | 深红色 | 红色 | 正面数 < 难度 |

**聊天框布局（从上到下）**
- 顶部：左上角圆形用户头像 + 右侧【属性名鉴定结果】大标题 + 玩家姓名小字
- 分割线
- 难度等级：文字【难度等级】+ 数字
- 结果大字：居中显示（成功 / 失败 / 完美成功）
- 骰掷结果：文字【骰掷结果】+ 实际投出的硬币图标行
  - 正面硬币：亮色金币
  - 反面硬币：暗色金币
  - 硬币总数 = 属性值 + 加值修正

## 十一、技能页面规格（Tab-技能）

技能页面与物品页面整体布局一致，左侧为技能栏，右侧为技能列表。

---

### 技能栏（左侧，~275px）

技能栏分为三组，从上到下排列：

关于图标
| 操作 | 行为 |
|------|------|
| 左键单击 | 聊天框发送物品信息 |
| 右键 | 弹出菜单：【卸下】【查看/编辑】【发起对抗】 |
| 悬停 | 显示 Title 卡片 |

#### 基础技能槽（第1-2行，共6格）

- 形状：**八边形**，无文字标签
- 最多装备 6 个基础技能
- 未装备：显示 `assets/icons/Skill/Normalsin.webp`，暗色占位图
- 已装备：显示对应图片，如 `Envy_lv1.webp` / `Wrath_lv1.webp` / `Sloth_lv2.webp` 等，路径 `assets/icons/Skill/`
- 边框颜色对应罪孽属性色（如嫉妒 = 紫色，暴怒 = 红色）
- 悬停显示 Title 卡片

#### EGO技能槽（第3-4行左侧，共5格）

- 形状：**圆形**，格子正下方有等级文字标签
- 按等级顺序固定排列：ZAYIN / TET / HE / WAW / ALEPH（各1格，不可调换位置）
- 未装备：暗色圆形占位，显示对应等级标签
- 已装备：显示对应图片，边框颜色对应罪孽属性色，图片路径同上
- 悬停显示 Title 卡片

| 位置 | 等级标签 |
|------|---------|
| 第3行左 | ZAYIN |
| 第3行中 | TET |
| 第3行右 | HE |
| 第4行左 | WAW |
| 第4行中 | ALEPH |

#### 守备技能槽（第4行最右，共1格）

- 形状：**八边形**，无文字标签，视觉上与基础技能槽相同
- 仅能装备 1 个守备技能
- 未装备：`Normalsin.webp` 暗色占位
- 已装备：显示对应图片，边框颜色对应罪孽属性色
- 悬停显示 Title 卡片

---

### 技能列表（右侧）

工具栏与物品列表完全一致（★ / ▽过滤 / ⊞⊟ / ≡ / ＋）。

#### 过滤面板规格（技能专用）

**分类过滤**：基本技能 / 守备技能 / E.G.O技能

**罪孽过滤**：暴怒 / 色欲 / 怠惰 / 暴食 / 忧郁 / 傲慢 / 嫉妒，支持多选

**过滤逻辑**：不同维度之间 AND，同维度内部 OR

#### 列表布局

- 按类型分组：**基本技能** / **守备技能** / **E.G.O技能**
- 行高固定 18px

| 列 | 宽度参考 | 内容 |
|----|---------|------|
| 图标 | 32px | 技能图标，悬停显示 Title 卡片 |
| 名称 | 自适应 | 技能名 |
| 分类 | 80px | 斩击 / 打击 / 突刺 / 闪避 / 格挡 / 反击等 |
| 罪孽 | 60px | 暴怒 / 色欲 / 怠惰 / 暴食 / 忧郁 / 傲慢 / 嫉妒 |
| 数量 | 50px | 数字（通常为1） |
| 星芒 | 50px | 消耗的星芒点数 |
| 操作 | 80px | ▶发起对抗 / ⋮更多 / ★收藏 |

> 守备技能操作列**无▶发起对抗**（只有 ⋮更多 / ★收藏），因守备槽只有1格且装备逻辑不同。

---

### 技能栏装备规则

- 星芒不足时：拒绝装备，显示黄色警告提示
- 基础技能槽满（6格已装备）时：无法再拖入基础技能
- EGO技能槽每个等级只能装备1个，同等级替换时直接覆盖
- 守备技能槽只有1格，替换时直接覆盖

## 十二、战斗页面规格（Tab-战斗）

战斗页面左右分栏，左侧为状态栏，右侧为战斗技能区。

---

### 左侧：状态栏

#### 状态列表

| 列 | 内容 |
|----|------|
| 图标 | BUFF类型图标（彩色） |
| 名称 | BUFF名称 |
| 强度 | 数值 |
| 层数 | 数值 |
| 操作 | 【触发】黄色按钮 / 【删除】按钮 |

- 行高固定 18px
- 【触发】：手动触发该BUFF的效果
- 【删除】：直接移除该BUFF

#### 底部按钮

`+ 添加新的状态BUFF`，点击弹出添加弹窗。

#### 添加新的状态BUFF 弹窗
参考assets\icons\GUI\添加新的状态BUFF.png
下拉框参考assets\icons\GUI\下拉框.png

| 字段 | 类型 | 说明 |
|------|------|------|
| 选择BUFF | 下拉菜单 | 从预设BUFF列表选择（破裂/烧伤/流血等） |
    若选择的为自定义BUFF添加↓
| 自定义BUFF | 文本输入框 | 输入自定义BUFF名，与选择BUFF二选一 |
| 回合 | 下拉菜单 | 本回合 / 下回合 |
| 强度 | 数字输入 | 如：15 |
| 层数 | 数字输入 | 如：5 |
| 底部按钮 | — | 【添加】/ 【取消】并排，均为深棕色 |

---

### 右侧：战斗技能区

#### 基础技能区

**标题栏右侧按钮**
- 【激活】：将技能页面已装备的技能载入战斗槽，开始6-bag抽取
- 【清除】：清空当前战斗槽所有激活/预备状态，重置6-bag

**6个八边形技能格子横向排列**

每个格子的图层结构（从底到顶）：

| 层级 | 内容 |
|------|------|
| ① 底部发光层 | 激活 = 亮金光；预备 = 暗红光；未激活 = 无光 |
| ② 技能图标层 | webp图片，圆形蒙版裁切 |
| ③ 八边形边框层 | 罪孽属性色边框 |
| ④ 彩色小圆点 | 格子正下方，激活/预备状态辅助指示 |

> 发光效果使用 CSS `drop-shadow` 实现，无需修改 webp 图片本身。

**↺ 重置图标**
- 出现条件：该槽位装备的技能有绑定【相关技能】时才显示
- 功能：手动在主技能和相关技能之间切换

---

#### E.G.O / 守备技能区

- 5个圆形格子（EGO）+ 1个八边形格子（守备），横向排列
- 样式比技能页面更暗，无等级标签
- 无额外操作按钮

---

#### 行动值区

**标题栏右侧按钮**
- 【重置】：将行动点恢复至上限（3点）
- 【清除】：将所有行动点清零

**3枚硬币图标横向排列**

| 状态 | 样式 |
|------|------|
| 未使用 | 亮色金币 |
| 已使用 | 暗色金币 |

- 固定3枚，不增减，点击切换亮/暗状态
